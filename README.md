# mxchat 版本发布与客户端更新

本仓库只提供 Windows 安装包、更新元数据和发布说明；应用源码在 [iszkq/mxchat](https://github.com/iszkq/mxchat) 维护。以后修改代码请回到源码仓库，然后将新版本发布到本仓库的 Releases。

## 下载与更新

- [下载最新正式版](https://github.com/iszkq/mxchat-releases/releases/latest)。选择 `mxchat-版本号-Setup.exe`，不要下载 GitHub 自动生成的 Source code.zip（它仅包含此文档，不是应用）。
- 0.3.57 及更早客户端需要手工安装 0.3.58 一次；之后支持客户端「设置 → 关于 mxchat → 检查更新」。
- 正式版启动约 15 秒后及每 6 小时自动检查。下载由用户选择，显示进度并支持取消；验证后点击「重启安装」再次确认才安装。普通退出不会自动安装。
- 沿用原安装目录，不要删除本机数据。当前安装包未配置 Windows 代码签名，系统可能提示未知发布者；哈希校验不等同于发布者签名。
- 仓库必须保持公开，客户端不需要 GitHub 登录，也不应内置任何 Token。GitHub 网络不可达时可稍后重试或手动下载安装。

## 维护与发布

完整流程见 [RELEASING.md](RELEASING.md)。源码仓库先修改、测试和推送，再将同一次构建的安装包、blockmap、latest.yml、SHA256 发布到本仓库的同一个正式 Release。不能只上传 exe，也不能把最新元数据留在私有源码仓库。

每个版本说明都记录对应的源码提交号；私有源码访问仍需相应权限。不要覆盖已经发布的版本或附件，新修复应递增版本号。

具体小工具只在本地制作维护，不在本仓库托管或随客户端发布，旧的圣经 ZIP/摘要附件已移除。通用后台 Worker 可保留为额外附件，需自行部署。

## 小工具资源

支持 mxchat 内组件、独立窗口工具和软件安装包三种交互。组件安装，窗口工具安装后使用；软件始终下载，每次选择保存路径，可重复下载，不自动运行。详见 [小工具资源发布说明](RELEASING.md#小工具组件独立窗口与软件下载)。具体工具源码、数据和 ZIP 使用独立的本地维护/资源托管流程。
